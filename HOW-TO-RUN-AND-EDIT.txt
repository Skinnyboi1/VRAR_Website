==============================================================
  VR / AR MEETING ROOM SHOWCASE
  STEP-BY-STEP SETUP, RUN & EDIT GUIDE
==============================================================
This guide takes you from a BRAND-NEW, CLEAN WINDOWS COMPUTER
all the way to seeing the rooms in VR/AR on your phone.

Follow the parts in order:
  PART 1 - Install everything (one time, on a new PC)
  PART 2 - Put the project on the computer
  PART 3 - First-time project setup (one time)
  PART 4 - Run the app on the PC
  PART 5 - Make it appear on your PHONE (VR / AR via QR)
  PART 6 - Where to edit things (rooms, colors, text, models)
  PART 7 - Troubleshooting

Tip: anything shown like   php artisan serve   is a command you
type into PowerShell and press Enter.

==============================================================
  PART 1 - INSTALL EVERYTHING (one time, on a new computer)
==============================================================
You need 3 programs: Laragon (PHP+Composer), Node.js, and ngrok.

--- 1.1  Install Laragon (gives you PHP + Composer + a web server)
   1. Go to:  https://laragon.org/download/
   2. Download "Laragon - Full" and run the installer.
   3. Click through with the default options. Install it to the
      default location (C:\laragon).
   4. Open Laragon. Click the "Start All" button once to confirm
      it works (you can stop it again; we run the app another way).

   Check it worked: open PowerShell (press Start, type "PowerShell",
   Enter) and run:
        php -v
   You should see "PHP 8.1" or higher. If it says php is not
   recognized, close and reopen PowerShell, or restart the PC so
   the PATH updates.

--- 1.2  Install Node.js (only needed to COMPRESS 3D models)
   1. Go to:  https://nodejs.org/
   2. Download the "LTS" version and install it (default options).
   3. Check: in a NEW PowerShell window, run:
        node -v
      You should see a version number (e.g. v20 or v24).

--- 1.3  Install ngrok (lets your PHONE reach the site over https)
   Easiest way (Windows 10/11 has "winget" built in). In PowerShell:
        winget install ngrok.ngrok
   Then CLOSE and REOPEN PowerShell so it's on your PATH. Check:
        ngrok version

   (If winget is missing: download from https://ngrok.com/download,
    unzip ngrok.exe somewhere, and use its full path instead.)

==============================================================
  PART 2 - PUT THE PROJECT ON THE COMPUTER
==============================================================
The project must live inside Laragon's "www" folder.

   Final location must be:   C:\laragon\www\vr_showcase

   - If you have the project as a ZIP: unzip it so that the files
     (composer.json, artisan, the app/ folder, etc.) end up directly
     inside  C:\laragon\www\vr_showcase
   - If you use Git:
        1. In PowerShell run:   cd C:\laragon\www
        2. Then:                git clone <your-repo-url> vr_showcase

==============================================================
  PART 3 - FIRST-TIME PROJECT SETUP (one time)
==============================================================
Open PowerShell and go into the project folder:
        cd C:\laragon\www\vr_showcase

--- 3.1  Install the PHP libraries (creates the "vendor" folder)
        composer install

--- 3.2  Create the settings file (.env) if it isn't there
   Check if a file named ".env" exists in the folder. If NOT, run:
        copy .env.example .env

--- 3.3  Create the app key (only if APP_KEY is empty in .env)
        php artisan key:generate

--- 3.4  Install ngrok's free login token (one time, ever)
   1. Make a free account:
        https://dashboard.ngrok.com/signup
   2. Copy your token from:
        https://dashboard.ngrok.com/get-started/your-authtoken
   3. In PowerShell, paste it into this command:
        ngrok config add-authtoken PASTE_YOUR_TOKEN_HERE

Setup is now done. You won't repeat Part 1-3 again on this PC.

==============================================================
  PART 4 - RUN THE APP ON THE PC
==============================================================
   1. Open PowerShell in the project folder:
        cd C:\laragon\www\vr_showcase
   2. Start the app:
        php artisan serve
   3. Open your browser to:
        http://127.0.0.1:8000
   4. To stop it: click the PowerShell window and press Ctrl+C.

   You should see the gallery with the meeting rooms. Click a room
   to walk through it on the PC (mouse to look, W/A/S/D to move,
   or look at the floor and click to teleport).

   NOTE: This 127.0.0.1 address works on the PC ONLY. A phone cannot
   open it. For phones, use PART 5.

==============================================================
  PART 5 - MAKE IT APPEAR ON YOUR PHONE (VR / AR via QR)
==============================================================
Phones need a public https link (VR/AR requires https). The
included launcher script starts the app AND the public link
together, in one step.

   1. Open PowerShell in the project folder:
        cd C:\laragon\www\vr_showcase
   2. Run the launcher:
        powershell -ExecutionPolicy Bypass -File .\start-showcase.ps1
   3. Wait a few seconds. ngrok will print a line like:
        Forwarding  https://xxxx-xxxx.ngrok-free.dev -> http://localhost:8000
      (That https link is your public address.)
   4. On the PC, open the gallery page in your browser. A QR CODE is
      pinned to the BOTTOM-RIGHT corner of the page.
   5. Open the camera on your phone and point it at that QR code,
      then tap the link it shows.
   6. The first time, the phone shows an ngrok page that says
      "You are about to visit..." - tap "Visit Site".
   7. The showcase opens on your phone. Pick a room, then use:
        - "Room View"  = look around by moving the phone; look at the
                         floor and tap to walk. Put the phone in a
                         Google Cardboard viewer for VR.
        - "View in AR" = place the room in your real surroundings
                         (Android Chrome with ARCore).

   TO STOP: click the ngrok/PowerShell window and press Ctrl+C.

   IMPORTANT NOTES:
     - The free ngrok link CHANGES every time you restart it. You do
       NOT need to do anything - the QR on the page always points at
       the current link automatically.
     - Phone and PC do NOT need to be on the same WiFi (ngrok is a
       public link). But the PC running the launcher must stay on.

==============================================================
  PART 6 - WHERE TO EDIT THINGS
==============================================================

>>> THE ROOMS (names, text, which model, where you start)
    FILE:  config\rooms.php
    Each room is a block like:
        [
            'slug'        => 'iman-room',           // URL: /rooms/iman-room
            'name'        => 'Iman Meeting Room',   // card title
            'tagline'     => '...',                 // short line
            'description' => '...',                 // longer text
            'capacity'    => 8,                     // "Seats X"
            'features'    => ['A','B','C'],         // grey chips
            'model'       => 'meeting-room-iman.glb', // file in public\assets\models\
            'thumbnail'   => 'iman-room.jpg',       // optional preview image
            'accent'      => '#f0b89a',             // this room's color
            'spawn'       => ['position'=>'0 1.6 4','rotation'=>'0 0 0'],
            'transform'   => ['position'=>'0 0 0','rotation'=>'0 0 0','scale'=>'1 1 1'],
        ],
    - ADD a room: copy a whole block, paste it, change the values.
    - HIDE a room: it hides automatically if its 'model' file is
      missing from public\assets\models\.
    - 'spawn' = where YOU stand when the room opens.
        position 'X Y Z' (Y = height; 1.6 = standing eye level)
        rotation 'X Y Z' (middle number turns you; 90 = quarter turn,
                          180 = face backward)
    - 'transform' = moves the MODEL itself. Use if the room loads
      sunk in the floor (raise Y), too big/small (change scale, e.g.
      '0.5 0.5 0.5'), or facing wrong (rotation middle number).

    AFTER editing config\rooms.php, run once:
        php artisan config:clear

>>> COLORS / OVERALL LOOK
    FILE:  public\assets\css\app.css
    The palette is at the very top, in ":root { ... }". Edit the hex
    codes: --bg (background), --panel (cards), --text, --accent,
    --accent-2. Save and refresh the page.

>>> HOME PAGE HEADLINE / INTRO TEXT
    FILE:  resources\views\rooms\index.blade.php
    Look for <header class="hero"> - the big <h1>, the <p class="lead">,
    and the badges row.

>>> VIEWER BUTTONS / LIGHTING / SKY
    FILE:  resources\views\rooms\show.blade.php
    - Buttons are in <div class="viewer-dock">.
    - Lighting: the <a-entity light=...> lines (raise "intensity" if
      a model looks dark).
    - Sky/floor color: <a-entity id="env" ...>.

>>> MOVEMENT / TELEPORT / VR LOGIC (advanced)
    FILE:  public\assets\js\room-viewer.js
    Walk speed = "wasd-controls" acceleration in show.blade.php.

==============================================================
  PART 7 - ADD / REPLACE / COMPRESS A 3D MODEL
==============================================================
   1. In Blender:  File > Export > glTF 2.0
        Format = "glTF Binary (.glb)"
        Enable: +Y Up, Apply Modifiers, Materials, UVs, Normals.
   2. Save it into:  public\assets\models\
        Filename: letters, numbers, dashes ONLY.
        NO spaces, NO "#".   GOOD: room-4.glb   BAD: My Room #4.glb
   3. Point a room at it in config\rooms.php ('model' => 'room-4.glb'),
      then run:  php artisan config:clear
   4. If the file is big (over ~5 MB) it loads slowly. Compress it:
        (install the tool once:)
        npm install -g @gltf-transform/cli
        (then:)
        cd C:\laragon\www\vr_showcase\public\assets\models
        gltf-transform optimize "room-4.glb" "room-4-small.glb" --texture-compress webp --texture-size 1024 --compress draco
      Then point the room's 'model' at room-4-small.glb.

==============================================================
  PART 8 - TROUBLESHOOTING
==============================================================
  * "php is not recognized" -> reopen PowerShell, or restart the PC
    so Laragon's PATH takes effect. Make sure Laragon is installed.

  * Browser shows an error / blank page on http://127.0.0.1:8000
    -> run, in the project folder:
         composer install
         php artisan key:generate
         php artisan config:clear

  * "It loads forever / model never appears"
    -> the model file is too big. Compress it (PART 7 step 4).
    -> or the filename has a space/# - rename it (PART 7 step 2).

  * "Room shows a plain placeholder with a sign"
    -> the 'model' name in config\rooms.php doesn't match the file in
       public\assets\models\, or the file is missing.

  * "Model is invisible / sunk in floor / facing away"
    -> adjust that room's 'spawn' and 'transform' (PART 6),
       then: php artisan config:clear

  * Launcher error: "Unexpected token '}' ..." when running
    start-showcase.ps1
    -> The .ps1 file has a non-ASCII character (e.g. a "fancy" dash,
       smart quote, or accented letter) and Windows PowerShell misread
       it. Keep the script PLAIN ASCII: use a normal hyphen "-" (not
       an em-dash) and straight quotes ' " (not curly ones). If you
       edited it, retype any special characters as plain ASCII and
       save again. (If you didn't edit it, the shipped version is
       already plain ASCII and should run fine.)

  * Phone: "ERR_NGROK_8012 ... upstream localhost:80"
    -> use the launcher (start-showcase.ps1). The PHP server must be
       on port 8000, and ngrok must point to 8000 (the script does
       this for you). Do NOT run "ngrok http 80".

  * AR button does nothing on the phone
    -> iPhone/Safari does NOT support WebXR AR (Apple limitation).
    -> Android: use real Google Chrome AND install "Google Play
       Services for AR" (ARCore) from the Play Store.

  * Edits don't show up
    -> room edits: run  php artisan config:clear
    -> any page: hard-refresh the browser (Ctrl+F5), or pull-to-
       refresh on the phone (files are cached).

==============================================================
  PART 9 - BOOKING SYSTEM + AUTH (Python AES/3DES crypto)
==============================================================
The app includes a room BOOKING system. Logging in / signing up is
handled by a small PYTHON service that does the cryptography:
  * Passwords  -> PBKDF2-HMAC-SHA256 (one-way hashing)
  * Sessions   -> token sealed with AES-256-GCM, then wrapped in 3DES.
The Python code lives in:  auth_service\  (see auth_service\README.txt)

--- 9.1  One-time setup
  1. Make sure SQLite is enabled in PHP (php.ini): the lines
        extension=pdo_sqlite
        extension=sqlite3
     must NOT have a ';' in front. (Already done on this PC.)
  2. Create the database tables (run once in the project folder):
        php artisan migrate
  3. Install the Python service dependencies:
        cd auth_service
        python -m pip install -r requirements.txt
        cd ..

--- 9.2  Running it (you need BOTH running)
  Terminal 1 - the Python auth service:
        cd C:\laragon\www\vr_showcase\auth_service
        python app.py                 (serves on http://127.0.0.1:5001)
  Terminal 2 - the Laravel app (as usual):
        cd C:\laragon\www\vr_showcase
        php artisan serve             (or start-showcase.ps1 for phone)

  Then in the browser:
   - Click "Book a room" (top-right) -> Register or Sign in.
   - Pick a room, a date, and an available time slot -> Confirm.
   - "My Bookings" lists your reservations; you can cancel them.
   - A room+date+slot can only be booked once (no double-booking).

--- 9.3  Where to edit booking things
  Time slots offered:     app\Http\Controllers\BookingController.php
                          (the SLOTS array)
  Booking pages design:   resources\views\bookings\*.blade.php
  Login/Register pages:   resources\views\auth\*.blade.php
  The crypto itself:      auth_service\crypto_core.py
  Auth service address:   .env  (AUTH_SERVICE_URL=http://127.0.0.1:5001)

--- 9.4  Troubleshooting
  * "auth service is not running" on login/register
     -> start it:  cd auth_service ; python app.py
  * "could not find driver" / SQLSTATE on migrate
     -> enable extension=pdo_sqlite and extension=sqlite3 in php.ini,
        then restart  php artisan serve.
  * Bookings/login do nothing after enabling php.ini extensions
     -> RESTART  php artisan serve  so it reloads php.ini.
